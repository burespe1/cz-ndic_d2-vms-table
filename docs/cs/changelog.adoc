== Historie změn dokumentace

// Revize dokumentace (MAJOR.MINOR.REVIZE). Změny formátu viz CHANGELOG.adoc ve specifikaci.
=== 1.3.0

* Nová dokumentace formátu `cz-ndic_d2-vms-table` verze 1.3 (DATEX II 3.7); nahrazuje dokumentaci formátu
  cz-ndic_d2-vms-table-v1.2 (DATEX II 3.6).
* Změny oproti verzi 1.2 (DATEX II 3.6):
** Struktura se nemění – výběr profilu je přenesen do modelu 3.7 beze změny tříd, prvků a kardinalit
   a data zůstávají platná. Mění se identifikace formátu a zdroje v hlavičce a pravidlo
   pro `publicationTime`; element `feedDescription` se nepoužívá.
** Verze tabulky a řadičů odpovídá vydání sítě Global Network (např. `260601`).
** Síť se dříve označovala `GlobalNetwork` a staničení jako `loc:LinearElementByCode` s modelem `mileage`; nově
   `linearElementReferenceModel` = `CZ-RSD-GlobalNetwork` a staničení číslem komunikace (`roadNumber`),
   u místních komunikací názvem (`roadName`) – shodně se situačními formáty.
** Kódy typů VMS `variableMesageSign` a `mobileVariableMesageSign` se nově zapisují správně
   `variableMessageSign` a `mobileVariableMessageSign`; ostatní kódy se nemění.
* Původ řešení: odkaz na obrázek celého řadiče (`vmsController/externalIdentifier`) je koncept převzatý
  z profilu ASFINAG.
